**Headline: Why choose one when you can master both? 🏛️🥋**

I’m thrilled to share that I have just completed and open-sourced my latest project: the **Nishad API Automation Hub**! 🚀

As an Automation Engineer, I’ve always believed that understanding different philosophies is key to building better systems. That’s why I built this "Polyglot" repository featuring TWO professional-grade frameworks for the same API:

1️⃣ **Rest Assured (Java)**: The industry standard for type-safety, POJO serialization, and deep architectural control.
2️⃣ **Karate DSL (BDD)**: The modern, low-code powerhouse for speed and simplicity.

**What’s inside the Hub? 🛠️**
✅ **Dynamic Architecture**: Config-driven setup using `BaseTest` and properties.
✅ **Advanced Scenarios**: Request Chaining, JSONPath extraction, and Multipart handling.
✅ **Data Management**: Serialization/Deserialization using Jackson & POJOs.
✅ **Visual Reporting**: Integrated **Extent Reports** for professional HTML dashboards.
✅ **Mental Mapping**: Mermaid diagrams to explain complex application flows.

I’ve also included a comprehensive **Study Guide & Q&A** section covering everything from basic GET requests to advanced Schema Validation—perfect for anyone preparing for API Automation interviews! 🎓📖

I believe in the power of community learning. If you are starting your API automation journey or looking to switch from Java to BDD (or vice versa), feel free to explore, fork, and learn!
